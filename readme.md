# rentoken.world

## 房租收益RWA数字化平台

rentoken.world 致力于将真实世界的房租收益资产（RWA, Real World Asset）引入区块链，实现房产租金收益的数字化、透明化和可交易化。

- 链上租金收益凭证，用户可轻松参与全球房产市场
- 享受稳定收益与资产流动性
- 资产安全、透明、可追溯

---

## Rentoken: Digital Platform for Rental Income RWA

rentoken.world is dedicated to bringing real-world rental income assets (RWA) onto the blockchain, enabling the digitization, transparency, and tradability of property rental income.

- On-chain rental income certificates for easy participation in the global real estate market
- Enjoy stable returns and asset liquidity
- Secure, transparent, and traceable assets
